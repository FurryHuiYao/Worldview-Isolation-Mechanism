# Worldview-Isolation-Mechanism   “世界观隔离”机制

一句老话“干掉你的可能不是同行，而是跨界而来”在论战是也一样能生效。
我的OC完完全全是个普通的人，不如说是一只狼龙兽人（我是混兽圈的）我也不希望我的OC受到伤害，这对论战的人来说可能没什么，但如果，如果那个人不喜欢被这样论呢？

二次元魔法少女、修仙网文大帝、克苏鲁神话外神、SCP基金会，甚至漫威宇宙的灭霸……这怎么比？这完全就是在拿着不同的“度量衡”在跨服聊天，鸡同鸭讲。

我个人不喜欢论战，因为我知道我不管怎么写我的OC战力都会被超越，还容易被正常论战的人贴上“死皮赖脸”或“臭不要脸”的标签。
这只是用来防论战的东西，我个人创造这机制也只是防止别人对我喋喋不休说什么“我的OC能毁灭宇宙”“OC绝对无敌”。

双方世界观都不一样，你跟我谈这个干什么？
